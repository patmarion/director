Iframe embed demo

A regular page that embeds the vtk-wasm 3D viewer as one element among others.

Live 3D view (iframe, fixed 16:10 aspect)

Host-page controls

These buttons live outside the iframe and act on the embedded view: resizing the card (the viewer's ResizeObserver follows), reloading the iframe, and sending commands into the viewer with postMessage.

Why an iframe?

The viewer runs in an iframe so its canvas can size independently of the host page. The host can then lay out, resize, and message the viewer like any other embedded component.

The floating panels are hidden by default for a clean embed; right-click inside the 3D view to toggle the scene panel or the debug info panel.
